我就划两下 · 元气手账
海外休闲界面改版（对照 Google Play casual 静态图）

本轮只改 Runtime / MenuUI 呈现与反馈：软 3D 釉面铬件、中文文案、按下与过关动效。
不改玩法、关卡、存档、云存档、IAA 点位与数值、音频资源映射、微信导出流水线。
本环境无团结编辑器，未出实机截图。

一、共享铬件
- MenuUI.Paper / Plate：白釉面板 + 软投影 + 高光，去掉黄胶带 / ink_paper 纸面。
- 新增 Extrude / SoftDepth / Gloss / Capsule / CountBubble，各页复用同一套软 3D 语言。
- 主按钮：珊瑚面 + 珊瑚底托 + 白字；次按钮：白釉 + 薄荷底托。不再贴 ink_brush / sticker_secondary。
- 进度条、页签选中改为珊瑚挤出芯片。
- 背景：浅紫底 + 粉/薄荷/葡萄散景，不再铺手账圆点。

二、文案（玩家可见仅中文，数字与 × 保留）
- 首页关卡芯片：Lv 23 → 第23关。
- 局内：第N关；道具名仍用涂鸦笔 / 冰冰饮 / 灵感镜。
- 暂停：已暂停；音效 / 音乐 / 触感；重新开始 / 返回首页 / 继续游戏。
- 结算：过关啦；获得金币；时间 / 步数 / 星数；看广告再领；下一关；再玩一次；返回首页。
- 新增 Zh.Cleared / NextLevel / PlayAgain / BackHome / WatchAdAgain 等，原有 Zh.* 未改语义。

三、首页 / 商店 / 成就 / 集章
- 首页插画进白釉板，开始游戏为珊瑚挤出条，左侧柠檬黄关卡芯片写第N关。
- 钱包条、生命/金币胶囊改为白釉挤出，不再铺纸纹。
- 底栏：白釉码头 + 选中珊瑚芯片，中文「商店 / 首页 / 成就」。
- 商店行、日签圆、补给卡、成就总览/里程碑、集章册格全部走同一套软 3D，不再贴纸带。
- 物件名保留 Home sticker showcase / Home current level / Source event / Shop row，避免 QA 断名。

四、局内 HUD / 道具 / 暂停
- 关卡：橙色挤出胶囊「第N关」。
- 计时：中央大白釉卡片，无进度底线（仍不创建名为 Panel 的 Image）。
- 暂停：紫色圆形底 + 原暂停图标；规则按钮仍在。
- 目标卡：白釉软 3D 砖，右上角 ×N 气泡。
- 底部三道具：大釉面砖 + 中文名 + ×N / 补充气泡。
- 暂停面板更高，开关带中文标注，主 CTA 继续游戏。

五、结算 / 失败
- 过关标题过冲弹簧入场，金币堆弹出，彩屑 36 片，奖励卡 Celebrate。
- 统计为用时、落子步数、按剩余时间估的 1–3 星（仅展示，不影响奖励）。
- 看广告再领仍走 DoubleCoins，次数与加成都不变。
- 下一关仍走原关卡结束插屏/进关逻辑；再玩一次走 Retry；返回首页走 ShowHome。
- 失败续时弹窗金币条改为柠檬黄挤出，文案与 IAA 不变。

六、反馈
- 按下：压缩到 0.86，并带短暂白高光；命中盒仍不缩放。
- 弹窗：从 0.72 过冲弹到 1。
- Feel 仍挂在 Press 上；开始游戏 / 继续游戏 / 下一关 / 商店购买 / 看广告再领 额外 Success。
- 触感仍尊重设置开关。Feel.cs.meta GUID 未改。

七、未改
- 500 关、存档/云存档、IAA 次数与单价、音频文件绑定、微信导出。
- WeChatHeaderLayout 仍跟踪钱包/HUD 子节点。
- 激励视频入口仍是原来的点位：续关、涂鸦笔、冰冰饮、灵感镜、生命、金币翻倍、金币补给。触发、次数和奖励数量都没动。

八、统一软 3D（本轮，对照目标稿）
- 不再把旧手账贴纸拼进新铬件。首页、商店、局内、暂停、结算共用 MenuUI 的圆角、挤出、投影和高光。
- 图集按 Unity Sprite.Create 的左下原点重打。menu_ui 与 sticker_semantic 的 y 都是底边坐标。英雄图、涂鸦笔、冰冰饮、灵感镜不再裁到木板碎片。
- 首页主视觉是铺满圆角板的软 3D 手账插画，不再留空白白框。开始游戏仍是珊瑚条，左侧柠檬黄芯片写第 N 关。
- 底栏图标换成同一套软 3D：商店门面、糖果、金奖杯。每日礼物和快乐集章也换成礼物盒与集章册。
- 局内：橙色第 N 关（下方粉色 ×目标数）、中央白计时、薄荷「规则」、紫色暂停。棋盘仍用原来的落子区域，边框是浅紫釉面，会跟着安全区走。三道具是粉/蓝/紫釉砖，图标为蜡笔、冰饮、金边镜，数量气泡同色。
- 商店三行用同一套道具砖和中文名。购买、每日次数、看视频领取的位置和 RewardPlacement 不变。
- 暂停仍是「已暂停」：音效 / 音乐 / 触感，重新开始 / 返回首页 / 继续游戏。
- 结算标题为「过关啦」，金币堆、时间 / 步数 / 星数、看广告再领、下一关、再玩一次、返回首页。去掉手账印章，避免和软 3D 铬件混贴。
- 背景只留浅紫散景，不再撒邮票贴纸。
- 玩家可见文案仍只有中文，数字和 × 保留。按下压缩和高光、过关弹出仍在。
