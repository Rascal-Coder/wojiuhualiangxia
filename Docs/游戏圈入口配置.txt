《我就划两下》游戏圈入口配置

当前配置：已启用；已填入开发者提供的「游戏内打开」首页 openlink，通过微信 PageManager 打开本游戏的游戏圈首页。
配置文件：Assets/Resources/Settings/game-club.json

1. 已接入提供的首页 openlink

enabled 保持 true，openlink 已填入微信公众平台生成的首页链接。它是公开跳转值，游戏客户端使用它，不需要 AppSecret 或 API Key。
游戏首页显示与现有手账风格统一的「游戏圈」入口。
玩家点击后，微信端使用官方 createPageManager().show({ openlink }) 打开首页；本地 Windows/编辑器只展示微信内打开提示。

如以后清空 openlink，入口将回退到官方 createGameClubButton，使用跟随首页按钮位置的透明原生点击区域，打开当前小游戏的游戏圈。Unity 的普通按钮回调不能模拟原生按钮点击，须由玩家实际点按。

进入商店、成就、关卡或弹窗时，原生点击区域会隐藏；退出首页时销毁。
弹窗关闭、返回首页及窗口大小变化后，会恢复并重新计算点击区域。
逻辑坐标按根 Canvas 和微信窗口尺寸换算，不重复乘以设备像素比。

2. 以后更换首页或跳到指定帖子、话题、活动

如果取得微信后台提供的真实「游戏内跳转 ID / OPENLINK」，
可以填入 openlink。它是微信后台生成的值，不是网页文档地址，也不是环境 ID。
非空时入口改用官方 createPageManager().show({ openlink })。
这条路径要求支持 createPageManager 的微信版本；失败或 12 秒超时会显示游戏内提示。
不填写这个值不妨碍当前的游戏圈首页入口。

3. 本地验证与真机确认

GameClubBuildChecks.Verify 只检查配置、SDK 参数签名和点击区域换算，
不会调用微信平台、创建真实按钮、导出、上传或发布。
Windows 预览可检查入口位置、统一字体及弹窗遮挡。
微信真机还需检查：原生入口点击能打开本游戏游戏圈；
商店/成就/设置弹窗/进入关卡时无残留点击区域；返回首页后可再次打开。
只有真机实际打开成功，才能确认微信端跳转效果。

4. 后台与帖子

请先在小游戏后台启用当前小游戏的游戏圈，并以官方身份发布帖子。
已准备的五篇文案见同目录「游戏圈首发5篇.txt」。
这里完成入口接入和文案准备，不代表已替你向游戏圈公开发帖。
真实玩家进入、浏览及互动是否满足流量主条件，以微信后台统计为准。
