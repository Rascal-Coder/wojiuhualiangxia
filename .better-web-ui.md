Export generated glyph pages from Assets/Editor/FriendsFonts with the renderer; do not substitute platform fonts for supported text. Precolored glyph images draw directly to the shared canvas, keeping names private and labels dynamic. Only unsupported nickname characters/emoji use native fallback. Font-image loading must not flash the system face before the game face.

No permission-settings button, simulated friends or fabricated scores. Cloud saves: automatically continue the latest meaningful game record with no local/cloud choice dialog. Compare normalized gameplay against the last acknowledged shared profile; equivalent records and changes confined to one side reconcile silently. When both sides changed, compare original gameplay edit times, never upload/connection times when an actual edit time is available. Avatar edits, full-heart clocks, expired eligibility, device preferences and decorative board fields never refresh the gameplay clock. Freeze the original edit time with each durable retry; acknowledgements preserve newer unsent edits. Bound abnormal future clocks and use the authoritative remote revision for equal or unknown times. Legacy servers fall back to their upload timestamp until updated. Never max-merge wallets or overwrite active gameplay. Delay restoration until an idle home screen, then compare again; re-fetch after long waits or foreground refreshes. Automatically isolate known account switches and restore the target account, using fresh progress for an empty account. Back up both copies before divergent resolution or restoration, and stop if backup fails. Preserve device sound/music/haptics/motion settings. Settings show automatic-sync status and retry only.
Cloud startup: a valid raw local profile, including a saved first-level game, starts login/sync in the background; an empty installation awaits its first cloud restore. Never treat malformed local JSON as a new blank profile or overwrite it. Apply active-board/transition guards even before BootReady; refresh home labels after the loading fade if a cloud record arrived during it. Listen for WeChat network recovery and retry immediately while preserving durable pending writes; suppress duplicate online events and known-offline requests, and unregister the same listener on destruction. Keep periodic and foreground retry fallbacks.

Shop: each item has three purchase transactions per China calendar day. Select 1–3 units per purchase with minus/plus; default one. Unit prices: pen/lens 50 coins, freeze 40. No 30-unit holding cap and no inventory or pack-size labels. Show daily purchases as three shopping-bag stamps (bright remaining, faded spent), with the daily limit/reset stated once in the page subtitle; no repeated remaining-count sentences. Use the same selector for in-level replenishment.
